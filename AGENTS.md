# Repository Instructions

- Commit messages must be concise Angular/Conventional Commit style: use `<type>(optional-scope): <short imperative summary>`, keep the subject brief, and do not include long explanatory bodies, constraint/test narratives, or non-Angular sentence-style subjects such as `Align ALFWorld rollout with step-level training`.
- For large multi-file changes, include a short commit body summarizing the main change areas so the commit remains easy to understand later; keep it brief and avoid long narratives.
